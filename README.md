# drawexact-observe
Observability service and website for DrawExact user patterns

A google cloud function server to receive, store and analyse DrawExact user event telemetry events.

- This project is defined in the docs directory.
- Don't expect it to express every detail
- Expect it to have a few mistakes in the definition - it has been written hastily
- Don't attempt to dot all the i's and cross all the t's - better to get started and iterate from something that already runs and has tests
